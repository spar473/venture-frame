# Examples

The venture cases are presented in [`cases/`](../cases/README.md). Their project files live here:

| Folder | Case |
| --- | --- |
| [`nz_venture_screening`](nz_venture_screening/README.md) | 1. Venture screening |
| [`nz_first_round_retrospective`](nz_first_round_retrospective/README.md) | 2. First-round retrospective |
| [`nz_deeptech_vc`](nz_deeptech_vc/README.md) | 3. The original deep-tech study |
| [`external_proposals`](external_proposals/README.md) | 4. Model suggestions, reviewed by a person |

The other folders are small invented or synthetic projects that the engine's tests and the app's
starter gallery use: supplier selection and qualification, infrastructure procurement, evidence
compilation, calculated measurements, formula models and the classifier agreement benchmark. They
show that the engine itself is domain-neutral; they are not part of the venture showcase.
